## 一、产品定位

### 1.1 一句话定位

> **像搭积木一样搭建地图大屏——拖一个地图、拖几个卡片、配一下数据源，30 秒出一个大屏。**

### 1.2 类比

| 产品 | 做什么 | 我们做什么 |
|------|--------|-----------|
| Notion | 拖拽块搭建文档 | 拖拽块搭建大屏 |
| Retool | 拖拽组件搭建后台 | 拖拽组件搭建地图大屏 |
| Grafana | 拖拽面板搭建监控看板 | 拖拽面板搭建行业地图大屏 |
| 游戏关卡编辑器 | 拖拽元素搭建游戏关卡 | 拖拽元素搭建大屏场景 |

### 1.3 核心价值

| 角色 | 之前 | 之后 |
|------|------|------|
| **前端工程师** | 手写 Vue 组件拼装大屏 | 用编辑器生成 JSON，引擎自动渲染 |
| **产品经理** | 画 Axure 原型给开发看 | 自己拖拽搭出可运行的大屏 Demo |
| **甲方决策者** | 看 PPT 想象大屏效果 | 看到真实可交互的大屏 |
| **外包商** | 每个项目重新开发 | 编辑器里换个数据源就是一个新项目 |

### 2.2 核心流程

```
用户拖拽组件到画布
    ↓

    ↓

    ↓
保存为 JSON 配置文件
    ↓
```


### 3.2 画布区域（中间）

**核心交互**：

| 操作 | 效果 |
|------|------|
| 从面板拖拽组件到画布 | 创建组件实例 |
| 拖拽组件移动 | 改变位置 |
| 拖拽组件边缘 | 改变大小 |
| 点击组件 | 选中，右侧显示属性 |
| 双击组件 | 进入编辑模式（文本/数据源） |
| Delete 键 | 删除选中组件 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+C / Ctrl+V | 复制 / 粘贴 |
| Ctrl+S | 保存 JSON |

**画布特性**：

| 特性 | 说明 |
|------|------|
| 网格对齐 | 组件自动吸附到网格（可开关） |
| 标尺 | 顶部和左侧显示像素标尺 |
| 缩放 | 画布可缩放（50%-200%） |
| 多选 | Ctrl+点击或框选多个组件 |
| 图层顺序 | 拖拽调整组件的 z-index |
| 参考线 | 拖拽时显示对齐参考线 |
| 大小指示 | 拖拽时实时显示尺寸 |

## 四、数据绑定系统

### 4.1 数据源配置

每个可数据驱动的组件都需要绑定数据源：

```
┌─ 数据源配置 ──────────────────────┐
│                                    │
│  来源类型:                          │
│  ○ 静态数据（手动输入）             │
│  ○ API 接口（REST）                │
│  ○ WebSocket（实时推送）            │
│  ○ 设备图层（从图层获取）            │
│                                    │
│  ── API 接口配置 ──                 │
│  接口地址:  [/api/devices    ]      │
│  请求方式:  [GET ▼]                │
│  刷新间隔:  [5 秒 ▼]               │
│  Headers:                           │
│  ├─ Authorization: [Bearer xxx]    │
│  └─ [+ 添加]                       │
│                                    │
│  ── 字段映射 ──                     │
│  数据路径:  [data.devices    ]      │  ← JSONPath
│  值字段:    [data.pressure   ]      │
│  标签字段:  [name            ]      │
│                                    │
│  [测试接口]  [预览数据]              │
│                                    │
└────────────────────────────────────┘
```

### 4.2 组件间数据联动

```
设备图层 (数据源)
    ↓ 点击设备
设备详情面板 (自动接收选中设备数据)
    ↓ 数据字段
数据指标卡 (绑定 设备图层.选中设备.压力)
    ↓ 数据字段
折线图 (绑定 设备图层.选中设备.历史压力)
```

编辑器支持**拖拽连线**建立数据绑定关系：

```
┌──────────┐    pressure    ┌──────────┐
│ 设备图层  │ ──────────→   │ 数据卡片  │
│          │    status      │          │
│          │ ──────────→   │ 状态标签  │
│          │                └──────────┘
│          │    history
│          │ ──────────→   ┌──────────┐
│          │                │ 折线图    │
└──────────┘                └──────────┘
```

### 5.2 JSON 核心概念

| 概念 | 说明 |
|------|------|
| `canvas` | 画布尺寸和背景 |
| `scenes[]` | 场景数组（每个场景 = 一个大屏页面） |
| `layers[]` | 地图图层（设备标记等需要在地图上渲染的） |
| `components[]` | UI 组件（面板、卡片、图表等叠加在地图上的） |
| `position` | 绝对定位 `{ x, y, w, h }` |
| `dataSource` | 数据源配置 |
| `config` | 组件专属配置 |
| `style` | 自定义样式覆盖 |
| `trigger` | 显示触发条件（如 `device-click` 时显示详情面板） |

## 六、编辑器操作流程

### 6.1 从零搭建一个大屏（5 步）

```
Step 1: 新建场景
  └→ 输入场景名、选择地图中心点

Step 2: 拖入地图
  └→ 从组件面板拖入"地图底图"到画布
  └→ 在属性面板配置主题、底图源

Step 3: 拖入设备图层
  └→ 从组件面板拖入"设备图层"到画布
  └→ 配置数据源（API 接口 / 静态 JSON）
  └→ 配置设备 Schema（字段定义）

Step 4: 拖入 UI 组件
  └→ 拖入"设备列表"到左侧
  └→ 拖入"详情面板"到右侧
  └→ 拖入"状态栏"到底部
  └→ 拖入"折线图""柱状图"等图表到合适位置
  └→ 每个组件配置数据源绑定

Step 5: 预览 & 导出
  └→ 点击"预览"查看最终效果
  └→ 点击"导出 JSON"保存配置
  └→ 渲染引擎读取 JSON 自动搭建大屏
```


## 十、技术实现方案

### 10.1 编辑器技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| UI 框架 | Vue 3 + TypeScript | 与组件库一致 |
| 拖拽 | vuedraggable / @vueuse/core | 拖拽排序 + 画布拖拽 |
| 画布渲染 | Canvas API 或 DOM 定位 | 组件在画布上的渲染 |
| 属性面板 | Vue 表单组件 | 动态表单 |
| JSON Schema | Ajv | 验证 JSON 配置合法性 |
| 撤销/重做 | 自研 history stack | 操作记录 |
| 图层管理 | 自研 | z-index 排序 |
| 保存 | localStorage + 导出文件 | 本地存储 + JSON 文件 |
