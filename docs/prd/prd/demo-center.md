## 一、目标

1. 让访客在 60 秒内感受到草果地图的能力（无需安装、无需代码）
2. 每个 Demo 对应一个具体行业场景，帮助客户"对号入座"
3. 所有 Demo 使用真实/模拟数据，展示最终效果

## 五、Demo 技术方案

### 5.1 架构

```
demo/
├── index.html              # Demo 总览页
├── common/                 # 共享组件
│   ├── DemoLayout.vue      # 统一布局（左地图 + 右面板）
│   ├── SimPanel.vue        # 模拟数据控制面板
│   └── CodeViewer.vue      # 源码查看器
├── basic/                  # D1: 基础地图
├── geojson/                # D2: GeoJSON 可视化
├── nlpg/                   # D3: NLPG 查询
├── copilot/                # D4: Copilot 交互
├── pipeline/               # D5-D7: 管网 Demo
├── grid/                   # D8-D10: 电网 Demo
├── water/                  # D11-D12: 水网 Demo
├── transport/              # D13-D14: 交通 Demo
├── compute/                # D15: 算力 Demo
└── telecom/                # D16: 通信 Demo
```

### 5.2 Demo 框架选型

| 方案 | 推荐度 | 理由 |
|------|--------|------|
| **VitePress + Vue 组件** | ⭐⭐⭐ | 与落地页/文档共享框架 |
| 纯 HTML + MapLibre | ⭐⭐ | 最简单但维护成本高 |
| Storybook | ⭐ | 组件库开发用，非展示用 |

### 5.3 Demo 组件设计

## 六、Demo 数据规范

每个 Demo 必须包含：

| 文件 | 内容 |
|------|------|
| `data/` | 模拟 GeoJSON / MVT 数据 |
| `config.json` | Demo 配置（标题/描述/图标/地图中心/缩放） |
| `index.vue` | Demo 主组件 |
| `README.md` | Demo 说明文档 |

数据要求：
- 模拟数据以 **武汉** 为背景（呼应 hb.cn 域名）
- 管网数据用武汉某真实区域的道路+管线
- 坐标系使用 GCJ-02（天地图兼容）
- 数据量控制在 **1000 要素以内**（快速加载）
