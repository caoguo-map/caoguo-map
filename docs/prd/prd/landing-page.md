## 一、目标

### 1.1 核心目标

落地页要同时服务 **两类访客**，在 30 秒内各自找到入口：

| 访客类型 | 他们是谁 | 他们要什么 | 入口 |
|---------|---------|-----------|------|
| **直接用户** | 开发者、技术负责人、甲方 IT | 了解引擎能力 → 试用 → 接入 | [开始使用] / [文档] / [演示] |
| **合作伙伴** | 系统集成商、行业 ISV、外包公司 | 了解合作价值 → 测算利润 → 联系合作 | [成为合作伙伴] / [合作方案] |

### 1.2 KPI

| 指标 | 目标值 |
|------|--------|
| 首屏跳出率 | < 40% |
| 合作伙伴页点击率 | > 8%（占总访客） |
| CTA 转化率 | > 3%（至少点击一个 CTA） |
| 平均停留时间 | > 90 秒 |

```javascript
  gis_cost_new: 8,         // 草果方案地图成本（仅人力）
  duration_old: 3,         // 传统方案周期（月）
  duration_new: 1,         // 草果方案周期（月）
  
  // 输出
  get profit_old() { return this.project_price - this.gis_cost_old - 15; },
  get profit_new() { return this.project_price - this.gis_cost_new - 5; },
  get margin_old() { return (this.profit_old / this.project_price * 100).toFixed(1); },
  get margin_new() { return (this.profit_new / this.project_price * 100).toFixed(1); },
};
```
