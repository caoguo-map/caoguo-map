## 一、阶段目标

在 Phase 1 管网标杆的基础上，**电网和水网并行开发**，3 个月内各完成 MVP：

**电网目标**：
1. 电网拓扑浏览器支持 5 级层级钻取（发电→输电→变电→配电→用户）
2. 停电分析器可在 3 秒内计算故障影响范围
3. 负荷热力图可实时展示台区/线路负载率
4. 可在 1 个试点供电公司完成数据接入

**水网目标**：
1. 水系拓扑图展示流域→河段→水库→闸站的层级关系
2. 洪水淹没模拟可基于 DEM 生成淹没范围多边形
3. 水库联合调度可视化支持多方案对比
4. 可在 1 个试点水利局完成数据接入

### 3.2 OutageAnalyzer — 停电分析器

#### 3.2.1 推演流程

```
选择故障设备（线路/变电站/配变）
    ↓
后端拓扑分析：
  1. 识别故障设备所在的供电区域
  2. 遍历下游所有受影响节点
  3. 统计受影响用户（居民/重要用户/工业）
  4. 检查是否有备用供电路径
    ↓
返回结果：
  {
    fault_point: GeoJSON,
    affected_area: GeoJSON,
    affected_users: {
      total: number,
      residential: number,
      commercial: number,
      industrial: number,
      important: [{ name, type, reason }]  // 医院/学校/政府等
    },
    restoration: {
      estimated_time: "2h",
      alternative_path: GeoJSON | null,  // 备用线路
      steps: [...]                        // 恢复操作步骤
    }
  }
```

#### 3.3.2 负荷预测模型

```python
# 简化版负荷预测（不使用复杂 ML）
def predict_load(station_id, hours_ahead=24):
    # 1. 获取历史同时段负荷（上周同日同时段）
    base = get_historical_load(station_id, weeks_ago=1, same_day=True, same_hour=True)
    
    # 2. 天气修正因子
    temp = get_forecast_temperature(hours_ahead)
    temp_factor = 1.0 + 0.02 * max(0, temp - 26)  # 高温每度 +2%
    
    # 3. 节假日修正因子
    holiday_factor = 0.7 if is_holiday() else 1.0
    
    # 4. 特殊事件修正
    event_factor = get_event_factor(station_id, hours_ahead)
    
    return base * temp_factor * holiday_factor * event_factor
```

### 4.2 FloodInundation — 洪水淹没模拟

#### 4.2.1 技术方案

**简化水文模型**（浏览器端可运行）：

```
输入参数：
  - 降雨量（mm）或上游来水量（m³/s）
  - 河段选择
  - DEM 地形数据（栅格）
  - 堤防参数（高度/位置）

计算流程：
  1. 降雨→径流计算（SCS-CN 模型简化版）
     Q = (P - 0.2S)² / (P + 0.8S)
     S = 25400/CN - 254
     CN = curve_number（按土地利用类型查表）

  2. 洪峰流量计算（推理公式法）
     Qp = 0.278 × C × i × A / t
     C = 径流系数, i = 降雨强度, A = 集雨面积, t = 汇流时间

  3. 水面线计算（简化恒定流）
     从上游断面开始，逐段推算水位
     依据：曼宁公式 V = (1/n) × R^(2/3) × S^(1/2)

  4. 淹没范围提取
     DEM 栅格 + 计算水位 → flood fill → 淹没多边形

输出：
  - 淹没范围多边形（GeoJSON）
  - 最大水深（栅格）
  - 受影响村庄/道路/耕地
  - 淹没面积/经济损失估算
```

#### 4.2.2 功能点

| # | 功能 | 优先级 |
|---|------|--------|
| F-1 | 参数面板：降雨量/来水量/河段选择 | P0 |
| F-2 | 淹没范围动态渲染（渐进式动画） | P0 |
| F-3 | 水深色谱（浅蓝→深蓝→深红） | P0 |
| F-4 | 叠加分析：淹没范围 × 人口/建筑/耕地 | P1 |
| F-5 | 多情景对比：不同降雨量下的淹没范围叠加 | P1 |
| F-6 | 撤退路径推荐：基于路网 + 淹没范围计算安全撤离路线 | P2 |

#### 4.2.3 验收标准

- [ ] 单次淹没模拟计算时间 < 5 秒（50m 分辨率 DEM）
- [ ] 淹没范围多边形生成时间 < 1 秒
- [ ] 水深计算与理论值偏差 < 15%（简化模型的合理精度）
- [ ] 叠加分析可在 3 秒内完成（100 万人口数据）
- [ ] 支持不同降雨情景的快速切换对比
