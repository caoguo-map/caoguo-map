## 按 PRD 核对并修复 9 个包功能

PRD 位于 `docs/prd/prd/`（phase-0~3）+ `docs/prd/maplibre-6networks-plan.md`，每个功能点标注 ✅/🟡/❌ 真实状态。原则：**只修复标注已落地(✅/🟡)但代码有真实缺口的功能，不擅自补全标注 ❌ 的未规划模块**。

### 关键修复 1：打通构建硬门槛（PRD D1 验收"组件包可独立安装使用"）
- `packages/maplibre/src/sourceUtils.ts` 的 `MlMapSourceApi`：**仅保留 `getSource` 必填，其余 addSource/addLayer/setData/removeSource 全部可选 + helper 内防御调用**。原因：各 System 把 `this.map.instance` 断言成"只含用到的方法"的局部类型（如 TrafficFlow 只有 addSource/addLayer、GridTopology 某处只有 getSource/removeSource），强制统一必填字段会冲突导致 5 个包 build 失败。改后 9 包 build 全绿。
- 配套：`TrafficFlow.ts` 的 mlMap 断言补回 `getSource`（upsertSource 需要）。

### 关键修复 2：3 处真实功能缺口（PRD 标 ✅ 但只完成算法层、缺渲染/UI）
- **transport TF-2 拥堵传播动画**：`TrafficFlow.renderCongestionSpread(seedEdgeId, hops)` + `computeHopDistance`（BFS 跳数）+ 红色高亮线层（透明度按 hop 渐变模拟动态扩散）+ click 绑定 onEdgeSelect。
- **compute C-2 节点详情面板**：`ComputeNodes.getNodeDetail(nodeId)` 纯函数（聚合算力/存储/GPU/状态）+ `onNodeSelect` 事件钩子 + render 中 click 触发（与同包卡片设计一致）。
- **telecom NH-2 告警闪烁标记**：`CellCoverage.renderFaultAlerts(health)` 渲染故障基站为红色圆点 + `requestAnimationFrame` 循环切换 circle-opacity 模拟闪烁 + clear 时 cancelAnimationFrame。

### 关键修复 3：测试基础设施
- `packages/compute` 和 `packages/transport` 的 `vitest.config.ts` 补 `setupFiles: ['../../tools/maplibre-test-setup.ts']`（之前只给 grid/telecom/pipeline/water 加了）。原因：这两包测试值导入 `@caoguo/maplibre` 触发 maplibre-gl 顶层 `createObjectURL`，jsdom 缺该 API 会崩。
- 新增 3 个测试：compute `ComputeNodes.test.ts`、transport `TrafficFlow.test.ts`、telecom `CellCoverage.test.ts`。全量 test 仍 0 失败（compute 11/telecom 12/transport 21）。
