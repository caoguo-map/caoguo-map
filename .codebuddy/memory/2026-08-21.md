### 算法亮点
- BurstSimulator 双向隔离：沿故障 pipe 两端 BFS 各找最近阀门组成关闭列表
- 隔离完整性 = source → 故障段任一端可达距离的最小值；全 source 都不可达 = Infinity
- 影响区域用凸包（Andrew's monotone chain）替代复杂多边形
- 健康评分 6 维加权（年龄25% + 材质20% + 土壤15% + 历史20% + 压力10% + 阴保10%）
- 状态处罚：damaged ×0.5, under_repair ×0.7, abandoned = 0
