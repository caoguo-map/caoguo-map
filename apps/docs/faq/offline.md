# 常见问题 · 离线 / 内网部署

**Q：纯内网无公网，文档站和地图能跑吗？**

A：可以。两者设计上都可完全静态化、离线分发：

- **文档站**：基于 VitePress 构建为纯静态文件，搜索采用本地索引（`search.provider=local`），不依赖公网。
- **地图离线**：业务数据走 `caoguo-offline://` 协议（T4），底图可经 Service Worker 的 Cache API 二级缓存（T5），并支持「空气隔离」模式禁网。

**Q：空气隔离模式是什么？**

A：T5 Service Worker 的一种运行模式，禁止一切外网请求，仅从本地缓存/离线存储取数，适用于强隔离的 G 端内网。详见《API · 离线能力》与《部署 · 离线/空气隔离》。

**Q：离线包太大怎么办？**

A：`packGeoJSON` 的 `maxZoom` 决定粒度与体积。管线类建议 `12–14`，区域级汇总建议 `10–12`；配合 LOD 在低 zoom 用聚合数据。
